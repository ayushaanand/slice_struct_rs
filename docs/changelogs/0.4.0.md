# 0.4.0 (Ecosystem Integration & Safety Enhancements)

## Added
* **Zero-Copy Deserialization (`zerocopy`):** Added the `#[slice_struct(zerocopy)]` attribute mode! This leverages the `zerocopy` crate (`FromBytes`, `Immutable`, `KnownLayout`) to allow safely mapping raw, dynamically sized byte buffers straight into `&Packet` or `&mut Packet` references.
* **Implicit `unpin`:** The `zerocopy` mode enforces position-independent layouts, so it automatically implies `#[slice_struct(unpin)]`. 
* **Ergonomic Unpin Views:** Introduced the `.view_mut_unpin()` convenience method for `unpin` and `zerocopy` structs, eliminating the boilerplate of manually wrapping `&mut self` into a `Pin::new(...)` just to obtain mutable slice iteration.

## Changed
* **Stabilized Offset Resolution (`offset_of!`):** Rewrote the internal pointer math and macro engine to leverage `core::mem::offset_of!` macro.

## Fixed
* **Miri & Stacked Borrows Provenance:** Completely eradicated internal Miri Undefined Behavior (UB) regarding `SharedReadOnly` vs `Unique` pointer tags. The macro now employs conditional internal cell-wrapping (`__SyncUnsafeCell` vs `MaybeUninit<u8>`) depending on the struct's addressing mode. It restores correct `Send`, `Sync`, and `RefUnwindSafe` auto-trait inference, while bypassing UB triggers when trailing bytes are mutated through `&self` (e.g. `DstMutex`).
* **Safe Fat Pointer Construction:** Refactored mutable pointer creation in `mut_from_bytes` to use `core::ptr::slice_from_raw_parts_mut` to preserve original pointer provenance over custom dynamically-sized bounds.
