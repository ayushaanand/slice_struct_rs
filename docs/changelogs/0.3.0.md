# 0.3.0 (The Builder Architecture)

## Added
* **The `SliceBuilder` API:** Replaced the monolithic `new_box_*` macros with the composable `SliceBuilder` pattern. You now instantiate structs via `.init_iter(...)` or `.init_def(...)`, which returns a builder. The builder exposes `.in_box()`, `.in_arc()`, and `.in_rc()`.
* **Zero-Cost `Arc`/`Rc` Support:** Structs can now be directly allocated into an `Arc` or `Rc` pointer without intermediate double-allocations or runtime moves!
* **`DstMutex` and `DstRefCell` Wrappers:** Added completely custom, memory-layout-guaranteed (`#[repr(C)]`) implementations of `Mutex` and `RefCell`. Because standard library wrappers have opaque layouts, they were incompatible with dynamically sized tail-slices. These custom wrappers safely hijack standard library lock mechanisms and use `UnsafeCell` to allow fully sound thread-safe interior mutability for DSTs!
* **`.with_mutex()` and `.with_refcell()`:** The `SliceBuilder` can elegantly wrap the struct in these new wrappers before moving it into an `Arc` or `Rc`.

## Breaking Changes
* **Removed `new_box_iter` and `new_box_def`:** The old monolithic constructors have been completely deleted.
* **Migration:** If you had `MyStruct::new_box_iter(...)`, you must replace it with `MyStruct::init_iter(...).in_box()`.

## Fixed
* **The Move-Then-Fixup Self-Referential Segfault:** A catastrophic memory corruption bug occurred when using standard `Arc::from(Box<T>)` because the bitwise move invalidated all internal `SliceHandle` absolute pointers. Solved via a safe Move-Then-Fixup post-allocation patch step that repairs pointers right before they are permanently pinned.
* **`fixup` Double Drop Segfault:** Fixed a highly nuanced UB bug where standard Rust assignment `(*ptr).field = new_val` implicitly ran the `Drop` destructor on uninitialized dangling pointers. Now strictly uses `std::ptr::write`.
* **Allocation Memory Leak:** Discovered and fixed via Miri. If an iterator panicked mid-write, elements were dropped but the main heap allocation itself leaked. Added `RawAllocGuard` to guarantee OS memory cleanup during panics.
* **Double-Drop in `init_def`:** Fixed a bug where `.init_def` would unnecessarily clone the element one extra time and then drop the original argument, skewing drop counters. It now cleverly clones $N-1$ times and moves the argument into the final slot.
